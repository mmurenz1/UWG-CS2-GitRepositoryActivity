How do I write a CSV file in Java with name and grade on each line?
Copilot said:
Copilot
To write a CSV file in Java with each line containing a name and a grade, you can use basic file I/O classes like FileWriter and BufferedWriter. Here's a simple example:

✅ Java Code Example



Java
import java.io.BufferedWriter;
import java.io.FileWriter;
import java.io.IOException;

public class CsvWriter {
    public static void main(String[] args) {
        String[] names = {"Alice", "Bob", "Charlie"};
        int[] grades = {85, 92, 78};

        String fileName = "grades.csv";

        try (BufferedWriter writer = new BufferedWriter(new FileWriter(fileName))) {
            writer.write("Name,Grade"); // Header
            writer.newLine();

            for (int i = 0; i < names.length; i++) {
                writer.write(names[i] + "," + grades[i]);
                writer.newLine();
            }

            System.out.println("CSV file written successfully.");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}

How do I read a CSV file and parse each line by comma in Java?
Copilot said:
Copilot
To read a CSV file and parse each line by commas in Java, you can use BufferedReader along with String.split(","). Here's a simple example:

✅ Java Code Example



Java
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

public class CsvReader {
    public static void main(String[] args) {
        String fileName = "grades.csv";

        try (BufferedReader reader = new BufferedReader(new FileReader(fileName))) {
            String line;

            while ((line = reader.readLine()) != null) {
                // Split the line by comma
                String[] parts = line.split(",");

                // Assuming the CSV has two columns: Name and Grade
                if (parts.length == 2) {
                    String name = parts[0];
                    String grade = parts[1];

                    System.out.println("Name: " + name + ", Grade: " + grade);
                }
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}

Java
import java.io.BufferedWriter;
import java.io.FileWriter;
import java.io.IOException;
import java.util.List;

public class StudentDataWriter {
    public static void saveToFile(List<String> studentData, String filePath) throws IOException {
        try (BufferedWriter writer = new BufferedWriter(new FileWriter(filePath))) {
            for (String line : studentData) {
                writer.write(line);
                writer.newLine();
            }
        }
    }
}

import org.junit.jupiter.api.*;
import java.io.*;
import java.nio.file.*;
import java.util.*;

import static org.junit.jupiter.api.Assertions.*;

    }

    @AfterEach
    void tearDown() throws IOException {
        Files.deleteIfExists(tempFile);
    }

    @Test
    void testSaveToFile() throws IOException {
        List<String> studentData = Arrays.asList(
            "Alice,85",
            "Bob,92",
            "Charlie,78"
        );

        StudentDataWriter.saveToFile(studentData, tempFile.toString());

        List<String> lines = Files.readAllLines(tempFile);

        assertEquals(3, lines.size());
        assertEquals("Alice,85", lines.get(0));
        assertEquals("Bob,92", lines.get(1));
        assertEquals("Charlie,78", lines.get(2));
    }
}

Here’s how you can write JUnit 5 tests for a method that loads student data from a CSV file. The goal is to:

Create a temporary CSV file with sample data.
Call the method that reads and parses the file.
Assert that the parsed data matches expectations.
✅ Example Method to Test



Java
import java.io.*;
import java.util.*;

public class StudentDataLoader {
    public static List<String[]> loadFromFile(String filePath) throws IOException {
        List<String[]> studentData = new ArrayList<>();

        try (BufferedReader reader = new BufferedReader(new FileReader(filePath))) {
            String line;

            while ((line = reader.readLine()) != null) {
                String[] parts = line.split(",");
                studentData.add(parts);
            }
        }

        return studentData;
    }
}

import org.junit.jupiter.api.*;
import java.io.*;
import java.nio.file.*;
import java.util.*;

import static org.junit.jupiter.api.Assertions.*;

class StudentDataLoaderTest {

    private Path tempFile;

    @BeforeEach
    void setUp() throws IOException {
        tempFile = Files.createTempFile("student_data", ".csv");

        List<String> lines = Arrays.asList(
            "Alice,85",
            "Bob,92",
            "Charlie,78"
        );

        Files.write(tempFile, lines);
    }

    @AfterEach
    void tearDown() throws IOException {
        Files.deleteIfExists(tempFile);
    }

    @Test
    void testLoadFromFile() throws IOException {
        List<String[]> data = StudentDataLoader.loadFromFile(tempFile.toString());

        assertEquals(3, data.size());

        assertArrayEquals(new String[]{"Alice", "85"}, data.get(0));
        assertArrayEquals(new String[]{"Bob", "92"}, data.get(1));
        assertArrayEquals(new String[]{"Charlie", "78"}, data.get(2));
    }
}
